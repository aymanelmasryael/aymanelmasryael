# Contributing to AEL Digital Studio

Thank you for your interest in contributing.

## Ways to Contribute
- Report bugs — open an issue with steps to reproduce
- Suggest features — open a feature request with use cases
- Improve documentation — fix typos, clarify wording
- Translate — help translate to Arabic, French, Spanish
- Share — star the repo, share on social media

## Commit Convention
We follow [Conventional Commits](https://www.conventionalcommits.org/):
- `feat:` new feature
- `fix:` bug fix
- `docs:` documentation
- `style:` formatting
- `refactor:` code refactoring
- `perf:` performance
- `test:` tests
- `chore:` maintenance

Example: `feat(identity): add accessibility statement`

## Pull Request Process
1. Fork the repository
2. Create a feature branch: `git checkout -b feat/your-feature`
3. Follow the existing code style
4. Write clear commit messages
5. Update CHANGELOG.md if applicable
6. Push and open a Pull Request

## Code Style
- 2-space indentation
- Semantic HTML5
- Mobile-first CSS
- Vanilla JS with `'use strict'`
- Accessibility (WCAG 2.2 AA)
- ARIA labels on interactive elements
