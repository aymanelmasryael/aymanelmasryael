## 🎯 نبذة

أحدّد رؤية المنتجات الرقمية وأنظّم الذكاء الاصطناعي لتحويل تلك الرؤية إلى واقع.

مؤسس **استوديو AEL الرقمي** — أصمم أنظمة الهوية البصرية، والتجارب المدعومة بالذكاء الاصطناعي، والمنصات الرقمية حيث تعمل الاستراتيجية والتصميم والتقنية كنظام موحّد.

**دبي · مصر · الكويت** — أتعاون مع عملاء حول العالم لإنشاء علامات تجارية مميزة، ومنتجات رقمية ذكية، وأنظمة تصميم طويلة الأمد.

## 🚀 المشاريع المميزة

### 🎨 منصة AEL Ωmega
نظام ذكاء لوني سيادي مع تحليل خريطة العلامة التجارية، وتصدير بـ 13 صيغة مع تكامل SHA-256، والتحقق من التباين المتوافق مع WCAG.

### 🧠 AEL Prompt Studio
منصة عمل لهندسة البرومبت مع تنسيق متعدد المزودين للذكاء الاصطناعي وتتبع التكلفة في الوقت الفعلي.

### 🎓 AEL Learn GitHub
دورة تفاعلية لـ Git و GitHub مع 23 وحدة، و10 مشاريع، واختبارات، وملعب تفاعلي، ونظام إنجازات.

### 📚 AEL Design System
مكتبة مكونات CSS بدون أي اعتماديات مع 12 مكوّنًا، وأكثر من 40 متغيرًا، ورموز تصميم.
